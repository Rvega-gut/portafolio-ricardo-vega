## Proyectos

### [Proyecto reingresion hospitalaria](./Proyecto%20reingresion%20hospitalaria)
**Python · Machine Learning**

Predicción de reingreso hospitalario en pacientes con diabetes usando el dataset *Diabetes 130-US Hospitals* (UCI). Incluye limpieza de datos, transformación de variables, selección estadística de features y comparación de modelos de clasificación (Random Forest, Regresión Logística, Naive Bayes).

---

###  [Persevera – Aplicación Web de Gestión de Facturas](./SQL)
**Python · Flask · MySQL · HTML/CSS**

Aplicación web para gestionar compras, ventas, proveedores, clientes e inventario de una empresa comercial. Desarrollada como proyecto universitario para el curso de Sistemas de Computación. Reemplaza el seguimiento manual en planillas por una interfaz dinámica conectada a una base de datos relacional.
